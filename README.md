# omni-infra

The foundational infrastructure repository providing machine-specific configurations, network patches, and shared manifests for the `k8s-scots-lab` bare-metal Kubernetes cluster.

## Relationship to k8s-cluster

```
┌─────────────────────────────────┐     ┌──────────────────────────────────┐
│         k8s-cluster             │     │          omni-infra              │
│                                 │     │                                  │
│  • Cluster template             │     │  • Machine-specific patches      │
│  • App-of-apps (48 ArgoCD apps) │     │  • Network topology configs      │
│  • Kustomize overlays           │     │  • Machine class definitions     │
│  • Helm values                  │     │  • Shared generic manifests      │
│  • Bootstrap manifests          │     │                                  │
│                                 │     │  Consumed by ArgoCD via the      │
│  PRIMARY deployment definition  │     │  `omni` Application (recursive)  │
└─────────────────────────────────┘     └──────────────────────────────────┘
         │                                          │
         └──────────── Both feed into ──────────────┘
                         │
                    ArgoCD GitOps
                 (k8s-scots-lab cluster)
```

The split ensures **infrastructure configuration** (networking, machine identity, NIC bonding) is decoupled from **application workloads**. ArgoCD consumes `omni-infra` via an Application pointing at the `manifests/` directory with recursive inclusion.

## Repository Structure

```
omni-infra/
├── helm/                    # Helm chart definitions for infra components
│   ├── base/                # Base chart references
│   └── overlays/scots-lab/  # Environment-specific Helm values
│
├── kustomize/
│   └── overlays/scots-lab/  # Environment-specific Kustomize patches
│                            # (machine configs, network topology)
│
├── manifests/               # Pre-rendered YAML consumed by ArgoCD
│                            # Generated by CI — do not edit manually
│
├── patches/                 # Reusable configuration patches
│                            # (network interfaces, NIC bonding, IP assignments)
│
├── generate-manifests.sh    # Manifest generation script (CI only)
└── renovate.json            # Mend.io dependency management config
```

## CI Pipeline

Like `k8s-cluster`, this repository uses a GitHub Actions pipeline to:
1. Render Kustomize overlays and Helm charts into static manifests
2. Commit the output to `manifests/`
3. ArgoCD automatically syncs changes from the committed manifests


## Dependency Management

This repository is integrated with **[Mend.io](https://www.mend.io/)** (formerly Renovate/WhiteSource) for automated dependency management.

| Feature | Details |
|---------|---------|
| **Configuration** | `renovate.json` in repository root |
| **Scope** | Helm charts, Kustomize bases, container image references |
| **Output** | Automated Pull Requests with version bumps |
| **Dashboard** | Central "Dependency Dashboard" issue tracking all upgrades |

Mend.io PRs should be **reviewed and merged regularly** to maintain security and feature currency. Do not close PRs or disable the dashboard without justification.
